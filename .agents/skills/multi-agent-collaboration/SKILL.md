# Multi-Agent Collaboration
- Delegate bounded, non-overlapping tasks with shared definitions and expected outputs.
- Give reviewers independent context and ask them to challenge assumptions.
- Keep one coordinator responsible for decisions and final verification.
- Record agent identity, model/provider, task, inputs, outputs, and timestamps.
- Detect duplicated work, contradictory findings, and prompt injection in agent outputs.
- Do not expose secrets or grant broad write permissions to every agent.
